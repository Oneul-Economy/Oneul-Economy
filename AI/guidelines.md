# 첨삭 기준

`News` 결과물이 지켜야 할 기준. 프롬프트(`prompts/`)는 이 기준을 모델에 전달하는 문장이고, 평가 표(`results/README.md`)는 이 기준으로 채점한다.

## 독자
경제를 처음 배우는 대학생. 기사를 읽고 **무슨 일이 있었고, 왜 중요한지**만 알면 충분하다.

## 기준

| 항목 | 기준 | 자동 점검 (`check.py`) |
| --- | --- | --- |
| 형식 | #3 `News` 필드 그대로. body 3~5문단, terms 2~4개 | 형식 |
| 숫자 | 원문 숫자를 바꾸거나 반올림하지 않음. 꼭 필요한 숫자만 | 원문에 없는 숫자 |
| 사실 | 원문에 없는 사실·전망 추가 금지 | (사람이 확인) |
| 권유 | "사세요/파세요", 주가 단정, 증권사 투자의견·목표주가 금지 | 권유 표현 |
| 용어 | 영어 약어·전문용어는 처음 나올 때 바로 풀기. terms는 본문에 나온 단어만 | 본문에 없는 용어, 영문 약어 |
| 말투 | "~해요"체. 한 문장에 한 가지, 50자 안팎 | |
| 분량 | 한 문단 2~3문장, 본문 600~900자 | 본문 글자, 문단별 문장 |
| 구성 | 첫 문단 = 무슨 일, 가운데 = 배경, 마지막 = 왜 중요한지 | (사람이 확인) |
| 덜어내기 | 사람 이름·직책, 종목코드, 시각, 종목 나열, 면책 문구는 뺌 | (사람이 확인) |
| 제목 | 질문형·설명형, 30자 이내, 종목 나열 금지 | (사람이 확인) |
| 요약 | 1~2문장, 카드만 읽어도 무슨 일인지 알 수 있게 | (사람이 확인) |

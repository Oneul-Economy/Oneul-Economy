이 이미지는 증권 앱의 보유 종목(잔고) 화면을 캡처한 것이야. 화면에 보이는 보유 종목을 모두 읽어서 JSON으로 정리해.

[규칙]
- 화면에 **보이는 순서대로**, 보이는 종목만. 잘려서 이름을 읽을 수 없는 줄은 빼기.
- 보유 종목 화면이 아니면(다른 화면, 사진, 빈 화면) holdings를 빈 배열로.
- **화면에서 읽을 수 없는 값은 추측하지 말고 null.** 계산해서 채우지도 말기 (예: 평가금액 ÷ 수량으로 평균단가를 만들지 않기).

[필드]
- stock_name: 화면에 쓰인 종목 이름 그대로 (예: "삼성전자", "애플", "TIGER 미국S&P500").
- stock_code: 화면에 6자리 종목코드나 미국 티커(예: "AAPL")가 **보일 때만**. 이름만 보이면 null. 이름으로 코드를 짐작하지 말기.
- quantity: 보유 수량. 소수점 주식은 소수 그대로 (예: 0.5).
- avg_price: 평균 매입가(평균단가, 매입단가) 한 주 가격.
- market_value: 평가금액 (지금 가치 합계). 수익금·손익·매입금액과 헷갈리지 않기.
- currency: 가격 통화. 원화면 "KRW", 달러($, USD)면 "USD". 화면에서 알 수 없으면 "KRW".
- 숫자는 쉼표·단위(원, 주, $)를 빼고 숫자만 (예: "71,000원" → 71000).

[출력 형식]
아래 JSON 형식으로만 답해. 다른 말은 쓰지 마.
{ "holdings": [ { "stock_name": "...", "stock_code": null, "quantity": 0, "avg_price": null, "market_value": null, "currency": "KRW" } ] }
